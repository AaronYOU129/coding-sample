# Research Coding Portfolio

Research coding projects by AaronYOU129, covering data collection, econometric estimation, experimental inference, and financial markets.

| Project | Research focus and technical skills |
| --- | --- |
| [Marketing Analytics & AI](marketing-analytics-ai/) | Web scraping, consumer experiment design, and analysis of AI-generated product recommendations. Includes additional cross-domain technical exercises. |
| [Econometric Estimation & Diagnostics](econometric-estimation/) | Fixed-effects price decomposition, normal-mixture maximum likelihood, and instrumental-variable estimation. Demonstrates numerical estimation, simulation-based tests, and diagnostic interpretation. |
| [Experimental Replication & Inference](experimental-replication/) | Replication of experimental results, permutation inference, multiple-testing adjustments, and coefficient plots. Demonstrates translating empirical specifications into reusable analysis code. |
| [Financial Markets & Innovation](finance-and-innovation/) | Rolling CAPM variance decomposition and patent novelty–valuation analysis. Demonstrates multi-source data preparation, financial analysis, and mechanism robustness checks. |

## Reproduction and data

Each project documents its own methods, dependencies, execution steps, and data availability. Some original inputs are excluded; the financial-markets and innovation datasets are stored separately and do not currently have a public download archive. Consult the project READMEs before running the code.
