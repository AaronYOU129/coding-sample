## Running the code

Follow the relevant task's README from that task's directory. Tasks 3 and 4 require your own API credentials; execution may incur API charges.

## Repository contents

This upload includes code, documentation, and selected existing results. Local credentials, virtual environments, logs, caches, the third-party Paper2Agent checkout, and Task 3's generated response files are excluded. The original assignment document is also excluded.

Task 4's local workflow requires separately setting up Paper2Agent and generating the agent. Its README describes the original local setup; references there to logs and the cloned framework refer to files not included in this repository.
